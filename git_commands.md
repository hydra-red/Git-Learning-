`Git Commands`

1. ** git status **: Tells if its already a git repository or not. If it is not, you can initialize it using `git init`.
2. ** git log **: Shows the commit history of the repository. You can use `git log --oneline` for a concise view.
3. ** git config **: Configures user information for commits. Use `git config --global user.name "Your Name"` and `git config --global user.email "your.email@example.com"`.
4. ** git diff --staged **: Shows the changes between the staging area and the last commit. Use `git diff` to see changes in the working directory.
